## 범위 제한
- M02에 벽 복원, 고블린 교체, 새 카드, 새 적을 섞지 않는다.
- 튜토리얼 벽 복원은 범용 환경 시스템으로 확장하지 않는다.
- 최종 픽셀 아트는 실제 화면 크기와 최소 키포즈 검증 후 제작한다.
- 제출 직전 새 대형 기능을 추가하지 않는다.
