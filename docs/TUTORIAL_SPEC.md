# 《언맥: 잇는 자》 튜토리얼 제작 기준

## 1. 문서 목적
이 문서는 대회판 튜토리얼의 스토리, 배경, 캐릭터, UI, 최소 키포즈, 언령 연출과 사건 순서를 정하는 단일 기준 문서다.

이미지 안의 문장·조작·수치가 이 문서와 충돌하면 최신 텍스트인 이 문서를 우선한다.

## 2. 참고 우선순위
1. 이 문서와 `MASTER_SPEC.md`, `UI_SPEC.md`
2. 주인공·고블린 최소 키포즈 시트
3. 튜토리얼 배경 최종 보정본
4. 전투 UI 최종 채택 시안
5. 캐릭터 제작 기준 보드
6. 스토리보드 A·B·C

스토리보드는 전체 흐름 참고용이며 완성 에셋이나 정확한 화면 배치를 의미하지 않는다.

## 3. 도입 스토리
주인공은 정식 전사나 언령사가 아닌 평범한 소년이다. 숲을 이동하던 중 낮은 절벽이나 낡은 지면에서 떨어지고, 그 충격으로 오래된 석벽과 바닥 일부가 무너진다. 무너진 자리에서 외부에서는 보이지 않던 좁은 틈이 드러나고, 소년은 몸을 낮추거나 비집고 그 안으로 들어간다.

안쪽은 시험실·신전·계승 의식장이 아니다. 과거 언령사 학살을 피해 살아남은 마지막 언령사가 오랫동안 숨어 지낸 생활 은신처다. 자연 동굴과 오래된 인공 석벽이 뒤섞여 있으며, 좁은 침상, 낡은 작업대, 먹그릇, 기록 종이, 봉인 흔적, 미완성 문장이 남아 있다.

거대한 마법 시설은 없지만, 누군가 마지막까지 언령을 기록하고 자신의 의지가 이어지기를 바랐다는 인상을 준다.

## 4. 배경

### 공간 구성
- 내부 약 70%, 외부 숲 약 30%
- 오른쪽의 불규칙한 파손부 너머로 나무줄기·잎·외부 빛 표시
- 넓은 기록실보다 작고 깊은 생활 은신처
- 침상, 작업대, 먹, 종이, 봉인 흔적, 미완성 문장 유지
- 과장된 제단·마법 장치 추가 금지

### 팔레트와 재질
- 청회색, 먹색, 탁한 녹색, 낡은 종이색 중심
- 옥색은 언령 흔적과 발동 지점에만 제한
- 붉은색은 적 행동·피해·위험 정보에만 제한
- 한지, 탁본, 먹 번짐, 낡은 돌·나무 질감

### 파손부 상태
같은 벽과 같은 구멍의 외곽을 유지하면서 상태만 바꾼다.

1. 평상시: 고블린과 활이 없는 빈 좁은 틈
2. 사격 상태: 고블린의 상체와 활이 걸리고 왼쪽을 조준
3. 복원 상태: 돌이 돌아와 팔·어깨·몸통 일부를 고정

고블린 전체를 벽으로 덮지 않는다. 단검 공격이 가능한 머리와 상체 일부는 내부에 남긴다.

### 실제 제작 보정
- 복원 핵심 돌은 4~6개
- 각 돌의 시작 위치와 원래 빈자리를 대응
- 긴 옥색 광선보다 돌의 실제 이동을 우선
- 주인공 하체와 바닥의 명도 분리
- 미완성 문장은 과발광보다 형태 인지성 우선
- 오른쪽 숲의 밝기가 고블린과 벽보다 튀지 않게 조정
- 세 상태에서 구멍 외곽과 주요 돌 배치 유지

## 5. 주인공
- 13~15세의 평범한 소년
- 작은 단검을 오른손에 사용
- 전문 전사나 정식 마법사처럼 보이지 않음
- 먹색·회갈색 중심 낡은 여행복
- 작은 가방과 최소 소품
- 과도한 장식과 흔들리는 천 최소화
- 피부와 얼굴은 배경보다 약간 따뜻하게 분리
- 복장에 옥색 상시 사용 금지

### 언령 자세
- 몸을 앞으로 크게 던지지 않는다.
- 선 자세와 중심축을 유지한다.
- 대상을 바라보며 손만 자연스럽게 뻗는다.
- 기본 대기에서 손만 교체한 듯한 경직된 자세를 피한다.

## 6. 고블린 궁수
- 마르고 민첩한 초반 판타지 몬스터
- 긴 귀, 굽은 목과 어깨, 가느다란 팔
- 짧은 활과 화살
- 너무 귀엽거나 거대하지 않음
- 튜토리얼에서는 오른쪽 파손 틈에 걸친 상태
- 얼굴·몸통·활·화살은 항상 왼쪽의 주인공을 향함
- 하체는 외부에 가깝게 남기고 머리·상체·활 든 팔 일부만 내부로 노출

## 7. 최소 키포즈
현재 키포즈 시트는 튜토리얼 구현용 최소 동작 라이브러리 v1이다. 최종 도트 원화가 아니다.

### 주인공
- 대기 3프레임
- 접근·달리기 4프레임
- 단검 공격 4프레임
- 피격 2프레임
- 언령 제스처 3프레임

원칙:
- 대기는 호흡과 어깨·옷자락의 미세 변화
- 달리기는 좌우 다리와 팔의 교차
- 공격은 준비 → 회전 → 명중 → 후속
- 공격 종료 후 원래 위치로 복귀
- 단검은 항상 오른손
- 언령은 준비 → 손 뻗기 → 회수
- 이펙트 없이도 실루엣으로 동작이 읽혀야 함

### 고블린
- 대기 3프레임
- 활 공격 4프레임
- 공통 피격·무장 흐트러짐 3프레임
- 벽 충돌·고정 2프레임

활 공격:
1. 활 들어 조준
2. 화살을 걸고 당기기 시작
3. 시위를 최대로 당김
4. 왼쪽으로 발사

공통 피격·무장 흐트러짐:
- 몸통과 머리 흔들림
- 활 각도 붕괴
- 시위에서 손이 풀림
- 화살이 떨어지거나 비틀림
- 일반 피격과 `멎는다` 취소 반응에 재사용
- 마지막 상태만 회복 또는 취소로 분기

벽 고정:
- 돌아온 돌이 팔과 어깨에 충돌
- 몸통 옆까지 맞물려 활 사용 불가
- 고블린이 몸을 빼려는 반응
- 머리와 상체 일부 노출

정확한 프레임 속도, 픽셀 이동량, 히트스톱은 실제 Phaser 검증 후 결정한다.

## 8. 전투 UI
- 왼쪽: 연결 언령 2슬롯
- 하단 중앙: 일반 카드 손패
- 하단 왼쪽: 체력·행동력·언령 자원
- 상단 오른쪽: 적 체력·현재 행동
- 하단 오른쪽: 턴 종료·덱·버림 수량
- 중앙: Phaser 전투 장면

일반 카드는 낡은 종이·기록 조각 인상, 연결 언령은 먹색 바탕과 옥색 글자·테두리를 사용한다.

카드 크기는 시안보다 약 10% 축소를 검토하며, 선택 카드만 위로 올라오고 밝아진다. 큰 언령 글자는 발동 중에만 표시한다.

## 9. 연결 언령
- 안정적으로 연결 가능한 언령은 최대 2개
- 대회판은 `멎는다`, `되돌린다` 2/2 고정
- 언령 선택·교체·연결 해제 화면은 구현하지 않음
- 언령은 슬롯에서 유효 대상까지 드래그

공식 조작:

`언령 드래그 → 유효 대상 강조 → 대상 위 드롭 → 발동`

## 10. 공식 튜토리얼 사건 순서
1. 소년이 일반 단검 기술을 사용
2. 고블린이 활 사격 준비
3. 플레이어가 `멎는다`로 현재 사격 행동 취소
4. 고블린이 다시 사격 준비
5. 플레이어가 `되돌린다`를 최근 무너진 벽에 사용
6. 돌이 원래 자리로 복원
7. 고블린의 팔·어깨·몸통 일부 고정
8. 사격 취소와 활 사용 불가
9. 노출된 틈에 `틈새 베기` 강화
10. 고블린 제압

한 번에 하나의 새 선택지만 열어 주는 유도형 튜토리얼로 만든다.

## 11. 일반 공격
1. 기본 대기
2. 카드 선택
3. 고블린 방향으로 접근
4. 공격 준비
5. 단검 접촉
6. 고블린 공통 피격·무장 흐트러짐
7. 주인공 원래 위치로 복귀

일반 공격 궤적은 따뜻한 미색·황갈색으로 표현한다.

## 12. `멎는다`
- 고블린 전체가 아니라 현재 활 사격 행동을 대상으로 함
- 시위 최대 당김 상태에서 연결 가능
- 실시간 타이밍 미니게임이 아님
- 드롭 후 당긴 상태가 멈추고 시위가 풀리며 화살이 떨어짐
- 자세 균형은 무너지지만 적 전체와 세계 시간은 계속 흐름

## 13. `되돌린다`

### 대상
- 고블린 본체 비대상
- 최근 무너진 벽과 대응 돌 4~6개
- 범용 환경 오브젝트 비대상

### 흐름
1. 슬롯에서 드래그
2. 파손부와 대응 돌 옥색 반응
3. 벽 위 드롭
4. 주인공의 절제된 손 제스처
5. `되 → 돌 → 린 → 다` 순차 등장
6. 글자가 흩어지는 동안 돌 역행
7. 돌이 고블린 팔·어깨·몸통 일부 고정
8. 현재 사격 취소와 활 사용 불가
9. 단검 반격 가능

### 타이포
- 현대 한글
- 판각·탁본형 골격
- 옥색, 먹 번짐, 닳은 가장자리
- 얇은 옥색 연결선
- 과한 마법진·폭발 금지
- 발동 종료 시 종이 섬유와 먹 입자처럼 흩어짐

## 14. 고정과 틈
- 고정은 튜토리얼 전용 상태
- 고정 중 활 사격 취소와 활 사용 불가
- 기존 `틈`과 연결해 `틈새 베기` 피해를 고정 수치만큼 강화
- 범용 치명타 확률·배율은 보류
- 정확한 피해 수치는 밸런스 단계에서 결정

## 15. 실제 에셋 처리
공식 제작 기준 후보:
- 튜토리얼 배경 최종 보정본
- 캐릭터 제작 기준 보드
- 주인공 키포즈 시트
- 고블린 키포즈 시트
- 전투 UI 최종 채택 시안

흐름 참고용:
- 스토리보드 A
- 스토리보드 B
- 스토리보드 C

현재 생성 이미지를 그대로 Phaser 런타임 에셋으로 사용하지 않는다. 실제 에셋은 고정 캔버스, 공통 기준점, 동일한 픽셀 크기, 투명 배경 스프라이트 시트로 다시 제작한다.

## 16. 알려진 이미지 오류
- 일부 고블린 방향·활·화살 방향 오류
- 일부 컷의 주인공·고블린 위치 오류
- 컷마다 달라지는 배경·구멍·캐릭터 크기
- 반복 생성으로 낮아진 픽셀 밀도
- 일부 손·무기·한글 오류

해당 오류는 공식 사양으로 승계하지 않는다.
