# UI / 앵커 계약

## 1. 기준 화면과 책임
- 논리 화면: 1280×720
- Phaser 내부: 640×360
- 앵커는 0~1 정규화 좌표로 교환한다.
- React: 드래그, 스냅 판정, 결과 미리보기, 카드·언령·HUD
- Phaser: 배우·배경·전투 연출·카메라·사운드
- 전투 수치와 상태 확정은 `src/core`에서 처리한다.

## 2. 공식 화면 배치
- 왼쪽: 연결 언령 세로 슬롯 2개
- 하단 중앙: 일반 카드 손패
- 하단 왼쪽: 플레이어 체력·행동력·언령 자원
- 상단 오른쪽: 적 체력·현재 행동
- 하단 오른쪽: 턴 종료, 덱·버림 수량
- 중앙: Phaser 전투 장면을 최우선으로 유지

1280×720에서 카드와 HUD가 전투 장면을 과도하게 가리지 않도록 한다.

## 3. 앵커 종류

### `actorAnchor`
- 적 또는 플레이어의 물리적 몸
- 일반 공격과 물리 기술의 대상

### `intentAnchor`
- 적의 현재 준비 행동
- `멎는다`의 대상
- 튜토리얼에서는 고블린 활 사격 행동을 나타낸다.

### `recentChangeAnchor`
- 가장 최근에 발생한 되돌릴 수 있는 변화
- M02에서는 플레이어 체력바 붉은 잔상 또는 최근 피해 영역
- 튜토리얼에서는 최근 무너진 벽과 대응 돌
- 두 대상은 같은 종류의 의미 앵커를 쓰더라도 별도 사건 데이터로 관리한다.

### 향후 후보
- `statusAnchor`
- `wordTargetAnchor`

현재 마일스톤에 필요하지 않으면 추가하지 않는다.

## 4. 일반 카드 조작
1. 카드에서 드래그 시작
2. 예상 물리 대상만 반응
3. 유효 대상 위에서 결과 미리보기
4. 드롭 시 사건 큐 등록
5. 잘못된 드롭 시 원위치 복귀
6. 연출 완료 후 상태 확정

### 카드 표시
- 낡은 종이·기록 조각 인상
- 미색·회갈색 중심
- 카드명, 비용, 핵심 수치는 항상 읽히게 유지
- 비선택 카드는 낮은 명도
- 선택 카드는 위로 올라오고 밝아짐
- 세부 설명은 선택 또는 마우스 오버 시 강조
- 최종 크기는 현재 시안보다 약 10% 축소 검토

## 5. 연결 언령 조작
1. 왼쪽 연결 언령 슬롯에서 드래그
2. 적용 가능한 의미 대상만 옥색으로 반응
3. 유효하지 않은 대상은 반응하지 않거나 낮은 명도 유지
4. 유효 대상 위에서 옥색 연결선과 결과 미리보기 표시
5. 드롭 시 언령 사건 발동
6. 잘못된 위치에서는 취소되고 자원 미차감

대상을 먼저 클릭한 뒤 언령 버튼을 누르는 방식은 사용하지 않는다.

## 6. 연결 언령 슬롯
- 세로 슬롯 2개
- 대회판 고정: `멎는다`, `되돌린다`
- 표기: `연결 언령 2/2`
- 먹색 바탕, 옥색 글자·테두리
- 일반 카드와 위치·형태·색을 명확히 구분
- 선택·교체·연결 해제 화면은 대회판에서 구현하지 않는다.

## 7. 시각 언어
- 일반 기술: 굵고 따뜻한 미색·황갈색 궤적
- 언령: 얇은 옥색 연결선과 이동하는 글자
- 적 행동: 짧은 붉은 범위와 동사
- 상태: 배우 몸 또는 HUD에 잔류하는 효과
- 최근 피해: 체력바 위 붉은 잔상
- 최근 환경 변화: 파손부와 대응 돌의 옥색 윤곽

## 8. `멎는다` UI
- 대상은 고블린 전체가 아니라 현재 활 사격 행동
- 고블린이 시위를 최대로 당긴 상태에서 `intentAnchor` 활성화
- 드래그 중 사격 행동 영역만 옥색 강조
- 드롭 후 당긴 자세가 멈추고, 시위가 풀리며 화살이 떨어짐
- 화면 전체 정지·시간 정지 효과로 표현하지 않는다.

## 9. `되돌린다` UI

### M02 체력 복구
- 최근 피해가 있을 때만 `recentChangeAnchor` 활성화
- 체력바 붉은 잔상이 대상임을 명확히 표시
- 결과 미리보기: 복구될 체력량
- 이미 복구한 피해는 대상 비활성화
- 최대 체력을 초과하지 않는다.

### 튜토리얼 벽 복원
- 고블린 본체는 비대상
- 최근 파손부와 대응 돌 4~6개만 옥색으로 강조
- 벽 위 드롭 후 복원 사건 시작
- 범용 배경 오브젝트 선택 UI는 만들지 않는다.

## 10. 언령 타이포
- 현대 한글을 사용한다.
- 대상 위 웹툰 특수 타이포처럼 표시한다.
- 판각·탁본형 골격, 옥색, 먹 번짐, 닳은 가장자리
- `되 → 돌 → 린 → 다` 순서로 왼쪽부터 등장
- 발동 종료 시 종이 섬유와 먹 입자처럼 바람에 흩어진다.
- 큰 언령 글자는 상시 UI가 아니라 발동 중에만 표시한다.
- 과한 마법진·폭발·레이저 연출은 사용하지 않는다.

## 11. 입력 잠금과 실패 처리
- 사건 큐 재생 중 카드·언령·초기화 입력을 막는다.
- 최종 포인터 좌표를 기준으로 드롭 대상을 다시 계산한다.
- `pointercancel`에서는 사건을 실행하지 않는다.
- 잘못된 대상·자원 부족·이미 처리된 변화에서는 상태와 자원을 바꾸지 않는다.
- 장면 교체 또는 연출 실패 시 확정 전 상태로 복구한다.

## 12. 튜토리얼 유도
- 첫 일반 공격에서는 필요한 카드만 강조
- 첫 활 사격에서는 `멎는다`만 활성화
- 두 번째 위기에서는 `되돌린다`만 활성화
- 벽 고정 후 `틈새 베기`를 강조
- 한 번에 하나의 새 규칙만 학습하게 한다.
