# 확정 결정

## 기본 결정
- 장르: 2D 사이드뷰 시네마틱 턴제 덱빌딩 로그라이트
- 구현: React + TypeScript + Vite + Phaser
- 아트: 시네마틱 픽셀 아트
- 손패: 기술 기록 조각형
- 일반 기술은 물리적 대상, 언령은 의미 대상을 드래그한다.
- 대회판 언령은 `멎는다`, `되돌린다` 중심이다.
- React는 UI와 드래그, Phaser는 배우와 연출을 담당한다.
- Phaser는 피해·비용·승패를 결정하지 않는다.

## 2026-07-22
- React 드래그와 Phaser 앵커 연결 기술 검증을 통과했다.
- 일반 기술은 적의 몸을 대상으로 한다.
- 언령은 행동·상태·최근 변화를 대상으로 한다.
- BattleEvent 직렬 사건 큐와 연출 중 입력 잠금을 다음 기반 작업으로 결정했다.
- 최종 픽셀 아트는 BattleEvent 큐와 `되돌린다` 검증 이후 제작한다.

## 2026-07-23

- `틈새 베기`, `멎는다`를 사건 큐로 이전했다.
- 연출 중 입력 잠금과 빠른 중복 입력 방지를 완료했다.
- 현재 마일스톤을 M02 `되돌린다: 최근 체력 복구`로 확정했다.

- 여러 피해 선택, 부활, 턴 전체 복구, 환경 복원은 M02 범위 밖이다.

## 2026-07-27 — 튜토리얼·시각 방향

### 공식 도입부
- 주인공은 정식 전사·정식 언령사가 아닌 평범한 소년이다.
- 소년은 숲에서 사고로 숨겨진 마지막 언령사의 생활 은신처를 발견한다.
- 장소는 시험실·신전·계승 의식장이 아니다.
- 은신처는 침상, 작업대, 먹, 종이, 봉인 흔적, 미완성 문장을 포함한다.
- 내부 약 70%, 외부 숲 약 30% 구도를 유지한다.
- 외부 숲은 오른쪽 파손부 너머로 보인다.

### 캐릭터
- 주인공은 13~15세의 평범한 소년이며 작은 단검을 오른손에 든다.
- 주인공의 언령 자세는 선 자세의 중심축을 유지한 절제된 손 제스처다.
- 첫 적은 활을 사용하는 마른 고블린 궁수다.
- 기존 돌짐승은 기술 검증용 임시 적으로만 유지한다.
- 고블린은 오른쪽 파손 틈에 걸쳐 있으며 항상 왼쪽의 주인공을 향한다.

### 튜토리얼 흐름
- 공식 순서는 `일반 공격 → 멎는다 → 되돌린다 → 고정 → 틈새 베기 강화`다.
- 첫 전투에서 두 언령을 모두 가르친다.
- 자유 전투가 아니라 사건 큐 기반 유도형 튜토리얼로 구성한다.

### 언령
- 한 번의 여정에서 안정적으로 연결 가능한 언령은 최대 2개다.
- 대회판은 `멎는다`, `되돌린다` 연결 2/2 고정이며 선택·교체 화면은 만들지 않는다.
- `멎는다`는 고블린 전체가 아니라 현재 활 사격 행동을 중단한다.
- `되돌린다`는 최근 변화에 사용한다.
- M02의 최근 체력 복구와 튜토리얼 벽 복원은 같은 원리를 공유하지만 별도 사건으로 구현한다.

### 환경 복원
- 벽 복원은 튜토리얼 전용 스크립트로 승인한다.
- 최근 무너진 벽 하나와 대응 돌 4~6개만 사용한다.
- 범용 환경 변경 이력, 임의 오브젝트 선택, 물리 복원 시스템은 보류한다.

### 고정과 틈
- 벽 복원 후 고블린은 튜토리얼 전용 `고정` 상태가 된다.
- 고정 중 현재 사격이 취소되고 활 사용이 불가능하다.
- 고정은 기존 `틈`과 연결해 `틈새 베기`의 고정 피해를 높이는 방식으로 사용한다.
- 범용 치명타 확률·치명타 배율·별도 능력치는 보류한다.
- 현재 기술 검증 코드의 `틈새 베기: 틈 +1`은 최종 카드 규칙으로 자동 승계하지 않는다.

### 이미지와 에셋
- 최신 텍스트 규칙이 이미지 안의 문장보다 우선한다.
- 참고 우선순위는 `텍스트 → 키포즈 → 배경 → UI → 캐릭터 보드 → 스토리보드`다.
- 키포즈 시트는 최소 제작 명세이며 완성 스프라이트가 아니다.
- 스토리보드 A·B·C는 흐름 참고용이며 방향·손·배경·텍스트 오류를 공식 사양으로 보지 않는다.
- 정확한 도트 밀도, 프레임 속도, 이동량, 히트스톱은 실제 제작 단계에서 조정한다.
