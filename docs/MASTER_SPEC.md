# 《언맥: 잇는 자》 — 대회판 기준 사양

## 1. 프로젝트 목표
- 제출 목표일: 2026-08-10
- 장르: 2D 사이드뷰 시네마틱 턴제 덱빌딩 로그라이트
- 기술: React + TypeScript + Vite + Phaser
- 핵심 원칙: **일반 기술은 사건을 만들고, 언령은 사건의 의미를 바꾼다.**
- 대회판은 핵심 차별점이 분명한 짧은 버티컬 슬라이스를 목표로 한다.

## 2. 기술 책임
- React: 손패, 연결 언령 슬롯, HUD, 결과 미리보기, 화면 흐름
- TypeScript `src/core`: 피해·비용·상태·승패 등 결정론적 전투 규칙
- `src/bridge`: React와 Phaser 사이의 정규화 좌표·사건 계약
- Phaser: 배경, 배우, 공격·피격·언령 연출, 카메라, 사운드
- Vite: 개발 서버와 웹 빌드
- Phaser는 피해량·비용·승패를 결정하지 않는다.

## 3. 렌더 기준
- 논리 화면: 1280×720
- Phaser 내부 전투 해상도: 640×360
- Phaser 캔버스는 전체 화면 뒤, React DOM UI는 투명 오버레이로 배치한다.
- 긴 한글 설명과 UI 수치는 DOM 텍스트를 유지한다.
- 픽셀 아트 확대 시 `pixelArt`, `roundPixels` 설정을 유지한다.

## 4. 공식 도입부
주인공은 정식 전사나 언령사가 아닌 평범한 소년이다. 숲을 이동하던 중 낮은 절벽이나 낡은 지면에서 떨어지고, 그 충격으로 오래된 석벽과 바닥 일부가 무너진다. 무너진 자리에서 외부에서는 보이지 않던 좁은 틈이 드러나고, 소년은 그 안으로 들어간다.

안쪽 공간은 시험실·신전·계승 의식장이 아니라, 과거 언령사 학살을 피해 살아남은 마지막 언령사가 오랫동안 숨어 지낸 생활 은신처다. 침상, 작업대, 먹그릇, 기록 종이, 봉인 흔적, 미완성 문장이 남아 있으며, 누군가 마지막까지 언령을 기록하고 자신의 의지가 이어지기를 바랐다는 인상을 준다.

상세 배경·캐릭터·튜토리얼 기준은 `TUTORIAL_SPEC.md`를 따른다.

## 5. 주인공과 첫 적
### 주인공
- 13~15세의 평범한 소년
- 작은 단검 사용
- 전문 전사·정식 마법사처럼 보이지 않는 낡은 여행복
- 단검은 모든 전투 프레임에서 오른손
- 언령 사용 시 몸의 중심축을 유지한 채 손만 절제되게 뻗는다.

### 첫 적
- 활을 사용하는 마른 고블린형 마물
- 긴 귀, 굽은 목과 어깨, 가느다란 팔
- 튜토리얼에서는 오른쪽 파손 틈에 몸을 걸친 상태
- 얼굴·몸·활·화살은 항상 왼쪽의 주인공을 향한다.

기존 돌짐승은 기술 검증용 임시 적으로만 취급하며 최종 튜토리얼 적으로 승계하지 않는다.

## 6. 일반 기술과 언령
- 일반 기술은 적의 몸과 같은 물리적 대상을 드래그한다.
- 언령은 행동·상태·최근 변화와 같은 의미 대상을 드래그한다.
- 언령은 연결 언령 슬롯에서 유효 대상까지 직접 드래그한다.
- 잘못된 대상에 놓으면 취소되고 자원을 소모하지 않는다.
- 사건 연출 중에는 추가 입력을 잠근다.

## 7. 연결 언령
- 여러 언령을 발견하고 보유할 수 있다.
- 한 번의 여정에서 안정적으로 연결할 수 있는 언령은 최대 2개다.
- 대회판에서는 선택·교체 화면 없이 `멎는다`, `되돌린다`를 연결 2/2 상태로 고정한다.
- 세 번째 언령 연결과 간섭은 세계관 배경으로만 유지하며 대회판 기능으로 구현하지 않는다.

> 두 뜻을 잇되, 셋을 품지 마라.  
> 셋째 뜻부터는 네가 말을 나누는 것이 아니라, 말이 너를 나눈다.

## 8. 공식 튜토리얼 전투 순서
1. 일반 단검 공격
2. 고블린의 활 사격 준비
3. `멎는다`로 현재 활 사격 행동 취소
4. 고블린의 두 번째 사격 준비
5. `되돌린다`로 최근 파손된 벽 복원
6. 복원된 벽에 고블린 고정
7. 노출된 틈에 `틈새 베기` 강화
8. 고블린 제압

튜토리얼은 자유 전투가 아니라 사건 큐에 따라 사용 가능한 선택지를 순서대로 열어 주는 유도형 구조로 만든다.

## 9. `멎는다`
- 고블린 전체를 얼리지 않는다.
- 현재 수행 중인 활 사격 행동을 중단한다.
- 대상은 적 행동 정보, 활시위, 당기는 손, 사격 행동 영역이다.
- 실시간 타이밍 미니게임으로 만들지 않는다.
- 시위 최대 당김 상태를 사건 큐의 연결 가능 상태로 제시한다.

## 10. `되돌린다`
### M02
- 플레이어가 가장 최근에 받은 피해 1회를 기록한다.
- 체력바의 붉은 잔상 또는 최근 변화 영역을 대상으로 사용한다.
- 최근 피해량만큼 체력을 복구한다.
- 같은 피해를 두 번 복구할 수 없다.

### 튜토리얼 환경 사용
- 최근 무너진 벽과 대응 돌 4~6개를 대상으로 한다.
- 벽 복원은 미리 정해진 상태 전환으로 구현한다.
- 복원된 돌이 고블린의 팔·어깨·몸통 일부를 고정한다.
- 범용 환경 변경 이력·물리 복원 시스템은 구현하지 않는다.

M02 체력 복구와 튜토리얼 벽 복원은 같은 세계관 원리를 공유하지만 별도 사건으로 구현한다.

## 11. 고정과 틈
- 벽 복원 후 고블린은 튜토리얼 전용 `고정` 상태가 된다.
- 고정 중 현재 사격이 취소되고 활 사용이 불가능하다.
- 고정은 기존 `틈`과 연결해 `틈새 베기`의 고정 피해를 높이는 방향으로 사용한다.
- 범용 치명타 확률·배율·별도 능력치는 구현하지 않는다.
- 정확한 피해 수치는 전투 밸런스 단계에서 확정한다.

## 12. 미술 방향
- 시네마틱 픽셀 아트
- 청회색, 먹색, 탁한 녹색, 낡은 종이색 중심
- 옥색은 언령·연결·최근 변화 강조에 제한
- 붉은색은 적 행동·피해·위험 정보에 제한
- 한지, 탁본, 먹 번짐, 낡은 돌과 나무의 재질감
- 특정 상용 작품의 그림체·캐릭터·타일셋을 직접 복제하지 않는다.

## 13. 대회판 범위 제한
### 포함
- 튜토리얼 전투 한 흐름
- 일반 단검 기술
- `멎는다`, `되돌린다`
- 고블린 궁수와 튜토리얼 은신처
- 최소 카드·HUD·연결 언령 UI
- 사건 큐와 입력 잠금

### 보류
- 범용 환경 상호작용
- 언령 선택·교체 화면
- 세 번째 언령 간섭
- 범용 치명타 시스템
- 여러 최근 변화 중 선택
- 다수 적·대형 카드 풀
- 제출 직전 새 대형 기능
